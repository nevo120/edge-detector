# Edge Detector

A Python application for detecting edges in images using different algorithms.

## Algorithms

- Simple Edge Detection
- Gradient Edge Detection
- Sobel Edge Detection

## Features

- Select an image from the computer
- Choose an edge detection algorithm
- Process the selected image
- Preview the result in the application

## Installation

Install Python, then install the required packages:

pip install -r requirements.txt

## Running the application

python ui.py

## Usage

1. Click the button to select an image.
2. Choose an algorithm.
3. Click Run.
4. View the processed image in the preview.
